## 功能与更新

- 普通 IPv4 UDP KNX/IP 隧道连接，实时观察组报文。
- ETS 组地址 XML 导入，显示名称、DPT 类型与数据长度。
- 手动组地址测试放在左侧，与右侧报文独立滚动，方便现场对照。
- 项目与网关设置支持折叠，收起保留关键信息。
- 局域网手机配对、授权测试、日志导出、目录历史与回滚。
